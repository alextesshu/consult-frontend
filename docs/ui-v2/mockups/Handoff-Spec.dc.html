Рух

Тривалість 150, 200 або 400 мс, крива cubic-bezier(.4,0,.2,1). Анімуються лише прозорість, колір, рамка, невеликий зсув (до 8px) і висота рядків grid. Без пружинок і паралаксу. При prefers-reduced-motion анімація вимикається.
