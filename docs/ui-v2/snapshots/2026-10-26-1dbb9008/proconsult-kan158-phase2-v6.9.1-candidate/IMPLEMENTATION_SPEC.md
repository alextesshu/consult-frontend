## Breakpoints (лише UI v2 публічного профілю)
- ≥ 1100 — дві колонки.
- 768–1099 — одна колонка, padding 32, фото 180×225 (768) / 200×250 (≥ 800) поруч з імʼям 40px, кнопки 48px; панель на всю ширину. Без липкої панелі.
- < 768 — компактний hero (фото 88×110), SectionNav стрічкою, MobileStickyBar; сторінка має padding-bottom = висота панелі + safe-area + 24.
- Глобальний header і UI v1 не змінюються.

## Ціна й вибір
- За замовчуванням формат **не вибрано**: «від <мінімальна> грн» у BookingPanel (ціни біля форматів), MobileStickyBar («Консультації онлайн / від 500 грн»), FinalCta («3 формати · від 500 грн» + «Обрати формат»).
- Після явного вибору — ціна вибраного у всіх трьох місцях; «Змінити» → фокус на BookingPanel.
- Формат + час: рядок 1 «<Назва> · <ціна>», рядок 2 «Чт, 29 жовт · 16:00» (Intl uk-UA, weekday short).
- Ціни — нерозривні пробіли, «грн».

## Режими
| | direct · є слоти | direct · слотів немає | request_only |
|---|---|---|---|
| Панель | формати + дні/слоти + мітка поясу | «Зараз вільного часу в розкладі немає. Залиште запит — …» | «Марія погоджує час особисто…» |
| Кнопка | без часу: «Обрати час» (перехід до слотів); з часом: «Продовжити · <дата>» | «Залишити запит» | «Залишити запит» |
| Липка панель | «Обрати час» / «Продовжити» | «Залишити запит» · «Вільного часу зараз немає» | «Залишити запит» · «Час — після запиту» |
- request_only ніколи не каже «немає доступних вікон».
- ⚠ **Implementation contract verification:** підтвердити поточну поведінку кнопки без вибраного слота в Vue і зберегти її.

## Часовий пояс
- Мітка фактичного поясу, у якому показано слоти: Europe/Kyiv → «Час за Києвом», інакше «Ваш місцевий час · <IANA>».
- Різницю з Києвом не обчислювати. Перемикача немає.

## Короткий опис (затверджена вимога)
- Редактор: лічильник «N / 160» (помаранчевий після 140), maxlength 160 для нового або зміненого опису, підказка «До 160 символів — показується повністю…».
- Профіль: повний текст, без line-clamp і обрізання слів.
- Раніше збережені довші описи: показуються повністю; редактор не обрізає їх автоматично, зберегти зміну можна лише ≤ 160.
- ⚠ **Перед реалізацією перевірити поточну frontend і backend валідацію** поля.
