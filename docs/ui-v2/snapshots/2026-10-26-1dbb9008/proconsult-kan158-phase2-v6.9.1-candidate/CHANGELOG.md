# CHANGELOG — KAN-158 Phase 2

## 2026-10-26 · v6.9.1-candidate — правки після UX-review (APPROVED WITH CHANGES)
1. **Без автовибору формату.** Початково — «від 500 грн» у панелі, липкій панелі, фінальному CTA («3 формати · від 500 грн» + «Обрати формат»). Після явного вибору — ціна вибраного формату скрізь.
2. **Без нового disabled-стану.** Головна кнопка без часу — активна «Обрати час», веде до слотів (затверджена семантика). Позначено як implementation contract verification.
3. **Часовий пояс спрощено:** одна мітка фактичного поясу слотів. Різниця з Києвом не обчислюється. Пояс «не визначено» прибрано зі специфікації.
4. **Короткий опис ≤ 160 — затверджена продуктова вимога** (лишається в дизайні): лічильник у редакторі, maxlength 160 для нового/зміненого, повний текст на профілі без line-clamp, старі довші описи — без втрати даних. Перед реалізацією — перевірка валідації.
5. **Breakpoints** 768–1099 і < 768 — лише UI v2 публічного профілю; глобальний header і UI v1 не змінюються.
6. **Приховано непідтверджене:** FAQ, «Досвід», «Мови», тривалість відео.
7. **M4 — повна мобільна сторінка:** резервний відступ під липку панель; футер і останні секції не перекриваються.

## v6.9-candidate — відносно Specialist Profile 2.1 (v6.8)
Панель запису + окрема картка контактів; липка мобільна панель з «від»; фінальний CTA з однією дією; планшет 768–820; мітка поясу; fallback фото; «З чим працюю» списком; освіта без закладу/року; відеовізитка без тривалості.
