# PRODUCT DECISIONS — KAN-158 Phase 2 · v6.9.1

## Затверджено
- Ліміт короткого опису 160 символів (продуктова вимога).
- Формат не вибирається автоматично.
- Візуальний напрям v6.9: панель запису, картка контактів, липка панель, фінальний CTA, планшет, навігація, fallback фото.

1. Поточна поведінка кнопки «Обрати час» без слота (implementation contract verification).
2. Поточна frontend/backend валідація короткого опису і поведінка для збережених довших.

## Лише концепції / майбутнє

- Різниця з Києвом поруч з міткою.

## Потребують backend
- FAQ як дані профілю.
- «Досвід», «Мови» — якщо їх немає в публічному API.
- Тривалість відеовізитки.

Анонімні питання, SLA відповіді, структуровані поля освіти, пряма оплата, семантичний пошук, зміни логіки booking/request, правил видимості контактів, глобального header, UI v1; повернення «немає доступних вікон» у request_only.
